# 💗 ShaadiMatch – Matrimonial Matchmaking Website

**Find • Connect • Forever**

ShaadiMatch is a responsive matrimonial matchmaking website designed to help users create profiles, discover compatible matches, shortlist profiles, express interest, and explore messaging features through a simple and elegant interface.

This project was developed as part of a **Web Development Internship Project** with Data Alcott Systems.

## ✨ Features

* 🏠 **Home Page** – Introduction to the platform and navigation to important sections.
* 📝 **Profile Registration** – Multi-step form for personal, family, career, and partner preference details.
* 🔐 **Login Page** – Demo login functionality for the frontend project.
* 📊 **User Dashboard** – Profile overview, completion progress, statistics, and recommended profiles.
* 🔎 **Find Matches** – Browse profiles and use search and filtering options.
* 👤 **Profile Details** – View profile information, education, career, family details, and partner preferences.
* ❤️ **Shortlist Profiles** – Save and manage shortlisted profiles.
* 💌 **Interests and Matches** – Explore sent interests, shortlisted profiles, and demo mutual matches.
* 💬 **Messaging Interface** – Chat interface with demo conversations.
* ℹ️ **About Us** – Information about the platform.
* 📩 **Contact Us** – Contact form and support information.
* 📱 **Responsive Design** – Designed to work across desktop and mobile screen sizes.

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, layouts, animations, and responsive design
* **JavaScript** – Form handling, navigation, profile interactions, and frontend functionality
* **LocalStorage** – Saving profile information and selected user actions in the browser
* **Font Awesome** – Icons
* **Google Fonts** – Typography

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or run it using the VS Code Live Server extension.
4. Register a demo profile and explore the dashboard and other features.

## 🧪 Testing Checklist

* Check navigation links between pages.
* Register a profile and verify that the dashboard displays the saved information.
* Refresh the page and check whether saved data remains available.
* Test profile search and filters.
* Test shortlist and interest buttons.
* Explore the Mutual Matches, Sent Interests, and Shortlisted sections.
* Test the messaging interface.
* Submit the contact form and verify its response.
* Check the layout on different screen sizes.

## ⚠️ Project Limitations

This is a **frontend demonstration project**. It does not currently use a backend server or database. Profile data and supported interactions are stored in browser LocalStorage, and some matching and messaging behavior is simulated for demonstration purposes.

Do not use real personal or sensitive information while testing.

## 🎯 Project Objective

The objective of ShaadiMatch is to demonstrate frontend web development skills through a multi-page matrimonial matchmaking platform with profile management, match discovery, interactive features, and responsive UI design.
